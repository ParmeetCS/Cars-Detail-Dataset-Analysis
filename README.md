# 🚗 Car Details Dataset Analysis

This project performs **Exploratory Data Analysis (EDA)** on a car details dataset using Python.  
It focuses on cleaning, analyzing, and visualizing data to extract meaningful insights about car prices, fuel types, and more.

---

## 🧩 Features

### 🧹 Data Cleaning
- Dropped null and duplicate values  
- Changed data type of `km_driven` column to **int**  
- Dropped unnecessary columns  
- Capitalized the first letter of all column names  

### 📊 Data Analysis
- Displayed dataset information and statistical description  
- Extracted **minimum and maximum selling prices** of cars  

### 📈 Data Visualization
- Visualized **number of cars under each fuel type** using Seaborn’s `countplot`  
- Plotted **Selling Price vs Year** using Matplotlib  

### 💾 Output
- Saved the cleaned dataset using `to_csv()`  

---

## 🧰 Tech Stack
- **Language:** Python  
- **Libraries:** Pandas, Matplotlib, Seaborn
